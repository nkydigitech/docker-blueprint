# Docker Blueprint — Zero to Hero

> *From `docker run` to multi-stage builds — one copy-paste lab at a time.*

A static, beginner-to-hero Docker learning platform. Nigerian-context analogies throughout.

Built by **Nkechi Anna Ahanonye** — Cloud & DevOps Engineer | AWS + Ansible + Terraform

## What's Inside
1. 10 hands-on labs with copy-paste commands + Expected Output
2. Capstone: NaijaFood App (Flask + Redis + Nginx)
3. Browser localStorage progress tracking (on the live site)
4. Dark/light toggle, responsive design
5. No build system — pure HTML/CSS/JS or MkDocs Material

## Quick Start
```bash
docker run -d -p 8080:80 --name blueprint nginx
docker run hello-world
```
