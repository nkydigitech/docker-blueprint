# Docker Blueprint — Zero to Hero

> **From `docker run` to multi-stage builds — one copy-paste lab at a time.**

A static, beginner-to-hero Docker learning platform designed for GitHub Pages. Nigerian-context analogies throughout.

Built by **Nkechi Anna Ahanonye** — Cloud & DevOps Engineer | AWS + Ansible + Terraform.

## What's Inside
- 10 hands-on labs with copy-paste commands + expected output
- Capstone: NaijaFood App (Flask + Redis + Nginx)
- Browser localStorage progress tracking
- Dark/light toggle, responsive
- No build system — pure HTML/CSS/JS or MkDocs Material

## Quick Start
```bash
docker run -d -p 8080:80 --name blueprint nginx
docker run hello-world
```
