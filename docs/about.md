# About — Docker Blueprint

Built by **Nkechi Anna Ahanonye** — Cloud & DevOps Engineer | I turn manual, 3 AM-breaking deployments into 1-min automated pipelines with AWS + Ansible + Terraform | Featured: 15-Module Ansible Lab with real terminal

## Purpose
A beginner-to-hero Docker learning platform built for DevOps students who need relatable, hands-on examples — not textbook theory. Nigerian-context analogies throughout.

## What Makes This Different
1. Every lab has copy-paste commands with Expected Output
2. Naija analogies: Danfo Bus, Jollof Pot, Water Drum, Owambe Party
3. Step-by-step instructions — not just commands thrown at you
4. Cleanup section in every lab
5. Production Notes for real-world deployment
6. Capstone project tying everything together

## Part of the Blueprint Series (17)
A 17-repo learning series covering the full DevOps stack: Ansible, Terraform, AWS, Azure, Kubernetes, Docker, Linux, GitHub, and more.
